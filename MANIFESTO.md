# Observatory Manifesto

## Declaration

We believe turn repository and ecosystem evidence into understandable health signals without confusing metrics with organizational truth is worth doing carefully, openly, and with respect for the people affected by the system.

## We stand for

- Evidence stays linked: make the commitment visible in behavior, not only prose.
- Missing data is visible: make the commitment visible in behavior, not only prose.
- Metrics inform rather than command: make the commitment visible in behavior, not only prose.
- Repositories remain comparable without flattening context: make the commitment visible in behavior, not only prose.
- Collection is least-privilege: make the commitment visible in behavior, not only prose.

## We reject

- concealed authority and irreversible surprise;
- lock-in disguised as convenience;
- claims of certainty without evidence;
- automation that erases human context;
- architecture that centralizes ownership merely because it is easier today.

## Commitment

We will keep Observatory independently understandable, honestly incomplete when evidence is missing, and open to revision when better evidence or lived experience contradicts current assumptions.

## Evidence and uncertainty

- **Observed:** The repository README establishes the intended boundary as the organization-wide visibility, maturity, health, and platform-observability system; significant implementation remains incomplete.
- **Decided for this draft:** The repository owns the bounded concern described here and participates through versioned contracts.
- **Proposed:** Target systems and later roadmap phases remain proposals until accepted and implemented.
- **Open question:** Which parts of this draft should become active in the first independently versioned release?
